# rzn vpn для Android

Предварительные сборки VPN-клиента rzn vpn на базе Xray-core. Пока функциональность дорабатывается, все версии публикуются как **Pre-release**.

**[Скачать 0.1.15 для ARM64](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/download/v0.1.15/rzn-vpn-arm64-v8a.apk)** · [Все версии и изменения](https://github.com/mokryi-hleb/rzn-vpn-releases/releases) · [Контрольные суммы](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/download/v0.1.15/SHA256SUMS)

Нужен Android 8.0 или новее и процессор ARM64. Эта сборка подходит для Pixel 10 Pro XL и других устройств ARM64; для 32-битных телефонов и эмуляторов x86 она не подходит.

## Установка и обновление

1. Скачайте APK по ссылке выше.
2. Откройте файл и при необходимости разрешите браузеру установку приложений.
3. При обновлении устанавливайте APK поверх предыдущей версии, без удаления приложения — подписка и настройки сохранятся.
4. Начиная с 0.1.15 следующие версии можно загрузить в приложении: «Настройки» → «Обновление приложения». Android попросит разрешить установку из rzn vpn и подтвердить обновление.
5. При первом запуске добавьте свою ссылку подписки и подтвердите запрос Android на подключение VPN.

Приложение не содержит готовой VPN-подписки. Это тестовые сборки; номер версии и изменения указаны на странице каждого релиза.

## Возможности

- Material You с цветами обоев, светлой/тёмной темой и адаптивной тематической иконкой.
- Импорт и фоновое автообновление подписок, компактный список серверов и проверка задержки.
- VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
- Режимы «Без маршрутизации», «Только заблокированное» и «Россия напрямую»; геоданные RunetFreedom и Re:filter.
- Автоматическое восстановление при смене Wi-Fi и мобильной сети.
- Включение и отключение VPN из шторки. Для добавления плитки откройте шестерёнку → «Настройки» → «Добавить в шторку».
- Маршрутизация и обновление геофайлов находятся в настройках. Для российских сайтов используется Яндекс DoH, для остальных — Cloudflare и Google.
- Predictive back с предпросмотром главного экрана при возврате из настроек.
- Сервер, подписку и маршрутизацию можно менять при включённом VPN. Изменения применяются автоматически; смена сервера или правил сопровождается коротким переподключением.
- Для новой установки по умолчанию используется «Россия напрямую»; ранее выбранный режим сохраняется.
- Частота автообновления подписки выбирается в настройках: раз в час, 6 или 12 часов, раз в сутки либо выключено. По умолчанию — раз в 6 часов; Android может отложить фоновое обновление для экономии батареи.
- Дата и время последнего обновления подписки, прогресс загрузки геофайлов.
- Проверка новых тестовых версий, загрузка с прогрессом и установка обновлений из настроек.
