# rzn vpn для Android

Тестовые сборки VPN-клиента rzn vpn на базе Xray-core.

**[Скачать актуальный APK для ARM64](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/latest/download/rzn-vpn-arm64-v8a.apk)** · [Все версии и изменения](https://github.com/mokryi-hleb/rzn-vpn-releases/releases) · [Контрольные суммы](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/latest/download/SHA256SUMS)

Нужен Android 8.0 или новее и процессор ARM64. Эта сборка подходит для Pixel 10 Pro XL и других устройств ARM64; для 32-битных телефонов и эмуляторов x86 она не подходит.

## Установка и обновление

1. Скачайте APK по ссылке выше.
2. Откройте файл и при необходимости разрешите браузеру установку приложений.
3. При обновлении устанавливайте APK поверх предыдущей версии, без удаления приложения — подписка и настройки сохранятся.
4. При первом запуске добавьте свою ссылку подписки и подтвердите запрос Android на подключение VPN.

Приложение не содержит готовой VPN-подписки. Это тестовые сборки; номер версии и изменения указаны на странице каждого релиза.

## Возможности

- Material You с цветами обоев, светлой/тёмной темой и адаптивной тематической иконкой.
- Импорт подписок PasarGuard, компактный список серверов и проверка задержки.
- VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
- Режимы «Без маршрутизации», «Только заблокированное» и «Россия напрямую»; геоданные RunetFreedom и Re:filter.
- Автоматическое восстановление при смене Wi-Fi и мобильной сети.
- Включение и отключение VPN из шторки. Для добавления плитки откройте шестерёнку → «Настройки» → «Добавить в шторку».
- Маршрутизация и обновление геофайлов находятся в настройках. Для российских сайтов используется Яндекс DoH, для остальных — Cloudflare и Google.
- Для новой установки по умолчанию используется «Россия напрямую»; ранее выбранный режим сохраняется.
