# mental deprivation для Android

Клиент туннеля на базе Xray-core с интерфейсом Material You, личным кабинетом и оплатой подписки из приложения.

**[Скачать 1.0.0 для ARM64](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/download/v1.0.0/rzn-vpn-arm64-v8a.apk)** · [Изменения](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/tag/v1.0.0) · [Контрольные суммы](https://github.com/mokryi-hleb/rzn-vpn-releases/releases/download/v1.0.0/SHA256SUMS)

Нужен **Android 9 или новее** и процессор **ARM64**. Сборка проверена на Pixel 10 Pro XL с Android 17. Версии для 32-битных устройств и x86 пока не выпускаются.

## Установка и переход с тестовых версий

1. Скачайте APK и откройте его. При необходимости разрешите браузеру установку приложений.
2. Устанавливайте поверх предыдущей версии, сохраняя приложение и его данные.
3. При переходе с 0.1.x на 1.0.0 скачайте APK по ссылке выше: прежний встроенный установщик не поддерживает смену сертификата. Android 9+ проверяет историю подписи и сохраняет настройки при установке поверх старой версии.
4. После установки включите туннель снова. Следующие обновления доступны в «Настройки» → «Обновление приложения»; установку подтверждает Android.

В 1.0.0 используется постоянный ключ подписи. Новые установки по умолчанию получают стабильные обновления; бета-канал можно выбрать в настройках.

## Подписка и личный кабинет

Нажмите значок пользователя в левом верхнем углу и войдите через Telegram. Сверьте код на телефоне и в боте, затем подтвердите вход. Для первого входа нужен доступ к Telegram. После входа можно сохранить одноразовые резервные коды и использовать их при недоступном Telegram.

В кабинете доступны срок действия и трафик подписок, зарегистрированные устройства, управление входами и история оплат. Кнопка «Продлить подписку» открывает выбор срока и опции с обходами, затем подтверждение суммы. Оплата проходит в официальной форме ЮKassa в браузере; приложение проверяет её результат на сервере. Номер карты в приложение не передаётся.

Также можно добавить собственную ссылку подписки. Готовая подписка в APK не включена.

## Возможности

- VLESS, VMess, Trojan, Shadowsocks и Hysteria2; Xray-core 26.10.31.
- Material You, адаптивные цвета, светлая и тёмная темы, тематическая иконка и predictive back.
- Отдельные списки «Серверы» и «Обходы», замер задержки и отображение трафика обходов.
- «Россия напрямую» по умолчанию или «Только заблокированное»; локальные адреса всегда идут напрямую. Геоданные RunetFreedom и Re:filter.
- «Исключения приложений»: выбранные приложения работают без туннеля. Популярные российские сервисы выбраны заранее; список можно изменить.
- DNS: «Умный выбор» с Яндекс DoH для российских сайтов, Cloudflare или Google.
- Автоматическое восстановление соединения при смене сети и после сна телефона. Доступность конкретного профиля зависит от сети оператора.
- Плитка включения в шторке: «Настройки» → «Добавить в шторку».
- Смена профиля, маршрутизации, DNS и исключений при активном туннеле с коротким переподключением.
- Фоновое обновление подписки с периодом, который передаёт её сервер, и обновление геофайлов с прогрессом загрузки.
- Автоматическая проверка версий, загрузка APK с проверкой суммы и подписи, установка через Android.

## Обратная связь и данные

[Сообщите о проблеме](https://github.com/mokryi-hleb/rzn-vpn-releases/issues), указав версию, модель телефона, Android и шаги воспроизведения. В настройках есть отчёт для поддержки без ссылок подписки, токенов, серверных адресов и списка приложений. Отчёт отправляется только вашим действием. Не прикладывайте ключи доступа к публичным обращениям.

Данные подписки и сеанс кабинета хранятся на телефоне в зашифрованном виде. Облачное резервное копирование отключено. Исключения приложений обрабатываются локально; список установленных приложений на сервер не передаётся.
